# Skills

## grilling / grill-me

Interview-driven technique to stress-test a plan, decision, or idea before building.

- **`grilling`** — model-invoked primitive. Interviews you relentlessly, working a
  "design tree" in rounds until every decision branch is resolved.
- **`grill-me`** — user-invoked command (`/grill-me`) that runs a `grilling` session.

Adapted from [mattpocock/skills](https://github.com/mattpocock/skills)
(`skills/productivity/grilling` and `skills/productivity/grill-me`).
